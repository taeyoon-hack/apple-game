# 🍎 사과게임

숫자 사과를 이어 합을 만들고 제한 시간 안에 점수를 올리는 브라우저 게임입니다.

## 게임 소개

8×8 격자에 1부터 9까지의 숫자가 적힌 사과가 무작위로 놓입니다. 사과를 드래그해 가로, 세로 또는 대각선으로 이웃한 칸을 이어 선택하고, 합계가 10의 배수가 되면 수확할 수 있습니다. 수확한 숫자만큼 점수를 얻고 해당 칸에는 새 사과가 나타납니다.

한 판은 60초이며, 최고 점수는 브라우저에 저장됩니다.

## 어떻게 만들었나요

[실습 가이드](./guide.md)의 프롬프트 예시를 바탕으로 Copilot Agent에 게임 구현을 요청한 뒤, 실행 결과를 확인하며 규칙과 디자인을 다듬었습니다. HTML, CSS, Vanilla JavaScript로 구성되어 별도의 라이브러리나 빌드 과정은 필요하지 않습니다.

## 실행 방법

저장소를 내려받은 뒤 `index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다. GitHub Pages에 배포한 경우 저장소의 Pages 주소에서 실행할 수 있습니다.

## 커스터마이징한 부분

- 제한 시간을 가이드 예시의 2분 대신 60초로 설정했습니다.
- 합계가 정확히 10일 때뿐 아니라 10의 배수일 때도 수확할 수 있게 했습니다.
- 최고 점수 저장, 남은 시간 표시, 선택 합계 안내와 신기록 축하 효과를 추가했습니다.
- 사과 이모지와 과수원 아케이드 테마를 적용하고, 마우스와 터치 드래그로 선택할 수 있게 했습니다.
